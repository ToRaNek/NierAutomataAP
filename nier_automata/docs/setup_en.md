# NieR:Automata - Archipelago setup

## Requirements
- NieR:Automata, **Steam v1.04**.
- Archipelago **0.6.8** or newer.

## Install
1. Copy `nier_automata.apworld` into the `custom_worlds` folder of Archipelago (or run `NierAutomataAP.exe`,
   which does it for you and opens the client).
2. Whoever generates the multiworld also needs the apworld.

## Play
1. Start NieR:Automata and begin a **new game** (one per seed).
2. Archipelago Launcher -> **NieR:Automata Client**, then connect to the server.
3. Keep the client window open; Archipelago commands (`!hint`, chat...) are typed there.
